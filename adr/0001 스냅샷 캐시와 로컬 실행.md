# ADR 0001: 스냅샷 캐시와 로컬 실행

- 상태: 현재 구현과 공개 준비 변경을 기록
- 기록일: 2026.10.25

## 배경

크롤러를 반복 실행할 때 같은 응답을 재사용해 원격 사이트 요청을 줄이고 디버깅 입력을 고정한다.
여러 언어의 크롤러와 브라우저가 같은 캐시를 사용하도록 HTTP(S) 프록시를 선택했다.
아래 결정은 현재 코드와 과거 작업 기록을 기준으로 정리했다. 과거 기록에 나온 속도와 용량 수치는 이번 검토에서 재측정하지 않았다.

## 결정

### mitmproxy addon에서 응답을 저장하고 재생한다

`request()`에서 캐시를 찾고 있으면 응답을 만든다. ALLOW 모드의 캐시 미스는 원격 서버로 보내며 `response()`에서 결과를 저장한다.
BLOCK 모드의 캐시 미스는 로컬 504 응답으로 종료하고 그 합성 응답은 저장하지 않는다.
`connection_strategy: lazy`로 업스트림 연결을 늦춘다.

이 동작은 addon의 허용 목록에 포함된 호스트에 적용한다. 목록 밖 요청은 통과한다.
BLOCK을 방화벽이나 전체 오프라인 모드로 해석하지 않는다. 네트워크 격리가 필요하면 별도 제어가 필요하다.

### 메서드와 전체 URL을 캐시 키로 사용한다

`HTTP 메서드:전체 URL`의 SHA-256을 파일명으로 사용한다. 상태 코드, 응답 헤더, base64 본문을 JSON에 저장한다.
파일 하나만 열어 응답을 확인할 수 있고 바이너리 응답도 저장한다.

단순한 고정 입력 실험을 위한 선택이다. 다음 요청 차이는 키에 반영하지 않는다.

- POST 요청 본문
- Cookie와 Authorization
- `Vary`에 따른 응답 차이

로그인 상태를 공유하거나 여러 사용자가 함께 쓰는 캐시에는 적합하지 않다.
동일 URL의 다른 POST 본문도 같은 응답을 재생할 수 있다. 쿼리 파라미터가 바뀌면 내용이 같아도 캐시 미스가 발생한다.
TTL, 무효화, 조건부 요청 재검증, 원자적 파일 저장은 구현하지 않았다.

### 호스트 목록을 두 단계에서 적용한다

`config.yaml`의 `allow_hosts`는 mitmproxy의 가로채기 범위를 정한다.
`target-sites.txt`의 호스트 suffix는 addon의 저장·재생 범위를 정한다.
목록을 변경할 때 두 파일을 함께 수정해야 한다. 하위 도메인은 허용하되 도메인 경계가 다른 호스트는 제외한다.

### CA와 캡처는 설치마다 생성하고 로컬에 보관한다

CA는 첫 실행 시 mitmproxy가 `ca/`에 생성한다. 생성된 CA 개인키, 인증서, 캐시와 로그를 Git에 포함하지 않는다.
클라이언트에는 공개 인증서인 `mitmproxy-ca-cert.pem`만 등록한다.
저장소에 있던 CA를 이미 신뢰한 환경에서는 기존 신뢰를 해제하고 새로 생성한 CA를 등록해야 한다.
공개 준비 변경은 OS나 브라우저의 신뢰 저장소를 직접 수정하지 않는다.

이전 커밋에는 CA 개인키와 운영 접속 정보가 남아 있다. 현재 파일 삭제와 `.gitignore` 추가만으로 Git 이력이 정리되지는 않는다.
공개 전에는 모든 공개할 ref의 이력을 정리하고 다시 검사해야 한다.

### Compose 포트는 loopback에만 노출한다

포트 매핑을 `127.0.0.1:8080:8080`으로 제한한다. 프록시는 인증 없는 로컬 실험용이며 외부 공개 서버 운영은 범위에 포함하지 않는다.
시스템 전체 프록시를 자동 설정하지 않고 curl, 브라우저, 크롤러에서 개별 지정한다.
컨테이너는 이 검토에서 실행하지 않으며 기존 운영 환경을 변경하지 않는다.

## 검증과 남은 범위

```sh
uv run --no-project --with mitmproxy python -m unittest discover -s tests -v
docker compose config --quiet
```

addon 동작은 임시 디렉터리와 합성 HTTP 요청·응답으로 검증한다. 실제 사이트를 크롤링하거나 외부로 요청을 보내지 않는다.
이 테스트는 프록시의 TLS 터널링, Docker 기동, 실제 CA 생성과 클라이언트 신뢰 설정을 증명하지 않는다.
